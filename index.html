LABORATÓRIO DE ESTUDOS / Início
JORNADA DAS 33 VIRTUDES • Protótipo pedagógico independente inspirado nos temas do Guia das Virtudes, de Eduardo Casarotto. Textos e atividades desta tela são originais.

Como explorar a plataforma

Comece pela Biblioteca, escolha uma virtude e estude as ideias e perguntas. Use a Roda para sortear uma reflexão, o Cinema para analisar escolhas, o Diário para registrar experiências e a Ponte para organizar mediações.

Seus registros ficam somente neste navegador, usando armazenamento local. O Painel apresenta participação nas atividades, não uma nota sobre seu caráter. Para salvar uma cópia, use o botão ⇩ no topo.

Esta é uma experiência educativa, não um instrumento de diagnóstico psicológico.
